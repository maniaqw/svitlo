# Світло ⚡
Telegram Mini App з офіційними графіками відключень електроенергії в Україні.
Побудовано на React, TypeScript, Vinext, Cloudflare Workers і D1.
Інтерфейс українською та російською мовами.

## Локальний запуск

Потрібні Node.js 24 LTS і npm.

```sh
npm ci
npm run db:local
npm run dev
```

Відкрийте http://localhost:5173. Перегляд доступний без токена бота.
Для локального запуску бота скопіюйте `.env.example` у `.dev.vars` і задайте значення.

## Перевірка

```sh
npm test
npm run typecheck
npm run build
```

## Дані й обмеження

Підтримуються Прикарпаттяобленерго, ДТЕК Дніпровські та ДТЕК Одеські електромережі.
Для інших операторів показуються обмеження й посилання на офіційні джерела.
Добові інтервали не замінюються тижневими чи сезонними графіками.
Якщо джерело тимчасово недоступне, показується останній успішний графік із попередженням;
збережені дані не використовуються для сповіщень і можуть бути неактуальними.

## Telegram і розгортання

Для власного розгортання створіть базу D1 у Cloudflare, вкажіть її ID у `vite.config.ts`,
налаштуйте production-конфігурацію Wrangler, застосуйте міграції та задайте секрети.
Готові production-ресурси й секрети до копії не входять.

Для webhook `/api/telegram/webhook` задайте `BOT_TOKEN`, `BOT_USERNAME`,
`MINI_APP_URL` і `TELEGRAM_WEBHOOK_SECRET`. У Bot API налаштуйте `setWebhook`
із `secret_token`, кнопку Mini App і команди `/start`, `/schedule`, `/stop`.

Планувальник викликає `POST /api/internal/reminders` кожні 5 хвилин із JSON `{}` та
заголовком `Bearer` зі значенням `REMINDER_JOB_SECRET`. `{"dry_run":true}` перевіряє
готовність без надсилання. Увімкніть `NOTIFICATIONS_ENABLED=1`; користувач має запустити
бота й дозволити сповіщення в Mini App. `/stop` вимикає підписку.
